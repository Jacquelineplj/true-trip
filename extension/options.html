TrueTrip settings

Set once; the block on every Booking.com card uses these. The local server must be running (npm run server in the truetrip folder).

Where you need to go each day: conference venue, office, campus. Add the city if the name is ambiguous.
When a hotel has no on-site parking, also search public parking within about 1 km. If no usable public rate is found, include a clearly labeled $50/night default estimate.
Include Google and Tripadvisor ratings in hotel lookups. Off by default to save cost.
If the hotel's on-site parking price is still unknown, try one parking-only GPT-4o-mini search targeting Expedia and Hotels.com. This may increase the page cost. Off by default.
